# 🇲🇦 Morocco Retail BI & Analytics

End-to-end Business Intelligence project analyzing a Moroccan retail
distribution network using Python, SQL Server and Power BI.

## 📌 Project Overview

This project develops a complete BI pipeline, from raw data preparation
and SQL Server data management to interactive Power BI dashboards.

The objective is to analyze sales performance, products, stores,
suppliers, categories and geographic distribution.

## 🛠️ Technologies

- Python
- SQL Server
- Power BI
- DAX
- Pandas
- Matplotlib
- Git / GitHub

## 🏗️ Architecture

Raw Data → Python → SQL Server → DAX → Power BI

## 📊 Key Analyses

- Sales performance
- Product performance
- Store performance
- Supplier analysis
- Category analysis
- Geographic analysis
- Regional distribution
- KPI monitoring
